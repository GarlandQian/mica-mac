# PRD: 概览流向彩带与双模式视觉焕新

## 背景

08-20 修复可读性与性能后，用户在真实数据 + **浅色模式**下反馈概览仍「多么的难看」（2026-08-23 三张截图），并要求「发挥创造性」。截图证据：

1. **拓扑（浅色）**：列标题互相叠字（「来源中规则」「代理铁理链出口」）；中性节点白色药丸在浅灰面板上几乎隐形；非活跃边线淡成雾气，整图没有视觉编码，只能靠眼睛追线。
2. **遥测图**：可接受，非本次重点。
3. **脉冲摘要条**：`累计 494.1…` / `累计 31.3…` 被截断；「按来源」分布条横贯整行，布局失衡。

## 已确认根因（代码核实）

1. **标题叠字（我的 bug）**：`OverviewTopologyHeaderGeometry.sliceWidth` 用 `2×邻列间距`——相邻标题各伸出一半必相撞；且边缘列经 clampedCenter 内推后与邻居重叠。正确闭合公式见 design.md §3。
2. **浅色洗白**：token 深色优先设计——浅色下 `surfaceRaised`(#FFFFFF) 节点画在 `surface`(#F5F6F7) 上 ≈2% 对比；`textTertiary.opacity(0.5)` 边线在浅色下有效透明度 ≈13%（tertiaryLabelColor 本身只有 ~26% alpha）。
3. **无视觉编码**：所有非状态边一个色，几十条贝塞尔线无法按流向追踪。
4. **摘要截断**：`WorkbenchConnectionPulseMetric` 用 `.frame(maxWidth: .infinity)` 五等分，detail 行 `lineLimit(1)` 被截断；分布条无宽度上限。
5. **边交叉最大化（用户二轮反馈「杂乱无章」）**：列内节点纯按名字排序（`sankeyNodeOrder`），完全不看流量走向——每条边都在与不相干的边交叉。

## 目标

在不改几何引擎、不改数据层、保留全部交互行为的前提下，把概览拓扑从「灰色蜘蛛网」升级为**有列身份色彩编码的流向图**，并让浅色模式成为一等公民。

## 需求

- R1 列身份色彩：四列类型（来源/命中规则/代理链/链出口）各配一个低饱和身份色（精确 token 表在 design.md §2，深浅双模式）；避开 accent 青绿与状态绿/橙/红。
- R2 流向彩带：默认态非状态边用「源列色→目标列色」横向渐变描边，宽度仍随流量；状态边继续由控制器上报状态色覆盖（契约不破）；选中路径 accent 实色 +1pt，其余边降为中性雾色。
- R3 节点药丸：中性节点 = 列色 14% 填充 + 列色 50% 1pt 描边（双模式可辨）；状态节点状态色填充、选中 accent 填充（不变）。
- R4 列头：修复 sliceWidth 公式（含边缘 clamp 与 gutter，任意列数/宽度不叠字）；标题下加 22×2.5pt 列色刻线（圆头）。
- R5 浅色对比度：所有中性绘制元素在浅色模式下达到可辨对比（节点描边、雾色边线均有显式 token，不依赖 tertiaryLabelColor 的低 alpha）。
- R6 脉冲摘要条修复：detail 文本不截断（fixedSize）；分布条加最大宽度；指标行布局平衡。
- R7 性能不回退：保留遥测 tick 零重绘门禁（policyStatusRevision）与单 opaque/linear Canvas；渐变只在结构/选择变化时重绘。
- R8 流向排序：列内节点按上游邻居流量加权重心（barycenter）前向排序，名字 tiebreak，完全确定性；第 0 列保持名字序。命中测试/标签/无障碍按 ID 与几何矩形派生，自动跟随。

- R9 真 Sankey 彩带（二轮反馈后用户确认，2026-08-23）：默认态边按其几何宽度（flow × valueScale，min 1pt，视觉地板 1.5pt）绘制为**闭合填充带**（顶/底双贝塞尔闭合路径，d3-sankey 同款构造），源列色→目标列色渐变，0.45 不透明度（社区最佳实践区间 0.4–0.6）；选中路径 accent 实色 85%；状态边状态色 70%；选中态其余边 edgeDimmed。中性节点改**实心列色块**（Sankey 锚点标准，无描边），dim 时 35%；状态/accent 节点行为不变。几何引擎零改动（边宽、y 打包、命中容差本就按带设计）。

## 非目标

- 不改遥测三图（截图 2 可接受）。
- 几何引擎仅放开「列内节点排序」一处（R8）；列分配、band 拆分、命中索引、labelRect 计算不改。
- 不恢复霓虹/辉光/发光效果；渐变仅用于边的流向编码，无装饰性渐变。
- 不动其它目的地、控制器层、数据层。

## 验收标准

- AC1 浅色模式截图级可读：中性节点清晰可辨、列标题零叠字、流向可按颜色追踪；深色模式不回退。
- AC2 任意列数（1..6）×任意面板宽度（最小/典型/最大）×中英文标题，列标题互不重叠且完整显示于 band 内（源码断言 + 边界单测）。
- AC3 状态契约：携带控制器上报状态的节点/边仍以状态色表达；accent 仅选中路径；无辉光/发光。
- AC4 行为全保留：悬停 tooltip、点击→inspector（7 case）、键盘、命中测试、暂停/冻结、无障碍、空/不可用态；`swift build` + 全量测试 + verifier 绿。
- AC5 性能：`MicaPerformanceBenchmarkTests` 绿且拓扑指标不回退；遥测 tick 仍零重绘（`policyStatusRevision` 门禁与 memo 测试保持）。
- AC6 摘要条：`累计 …` 全值显示不截断（fixedSize 断言），分布条有最大宽度（源码断言）。
- AC8 彩带形态：默认态边为填充带（源码断言闭合 Path + gradient fill），宽度取自 EdgeGeometry.width，不存在 0.75–2.5 描边 clamp；汇流处半透明叠加（用户目验）。
- AC7 流向排序：单测构造已知交叉场景，断言排序后列内顺序使边平行化；同一拓扑输入两次布局输出逐位一致（确定性）；无入边节点沉底且名字序。

## 风险

- 排序变化使既有布局断言测试需要同步（按名字排序的断言改为流向序）。
- 渐变描边比纯色贵：边数量级为数十条且仅结构变化时重绘，风险低；若基准回退则降级为源列纯色。
- 列色与状态色的可区分性依赖饱和度差（低饱和身份色 vs 系统状态色）——design.md 定色后由用户过目。
- 回滚点：7b6d651（本任务开始前 HEAD）。
