# Mica macOS 27 液态玻璃 UI 全量重构

## Goal

彻底重做 Mica 的原生 macOS 界面，使其成为以真实控制器数据为核心、具有 macOS 27 Liquid Glass 空间层次和专业工具效率的控制工作台。此次重构从视觉与交互结构重新设计，不保留当前 UI 外壳、卡片体系或自定义控件的兼容层。

用户价值：在一个窗口内快速辨认控制器状态、浏览稳定有序的策略组、切换节点、检查连接/规则/来源/日志并执行控制器操作；界面应清晰、精致、有明确材质层级，而不是由大量相似描边卡片组成。

## Confirmed Facts

- `Package.swift` 已将最低平台设为 macOS 27，可直接使用当前 SDK 的 SwiftUI Liquid Glass API，不需要旧系统回退层。
- 当前应用是 SwiftUI `NavigationSplitView` 专业工具，数据和控制器操作契约已经在上一任务中完成 SparkXie 对齐。
- 当前视觉依赖 `MicaStyle`、`MicaSurface`、`MicaPanel`、自定义按钮样式和大量硬编码背景/描边；现有 `glassEffect` 使用极低透明度，不能形成清晰的 Liquid Glass 层级。
- 用户明确授权自由发挥和彻底重构，不要求兼容旧 UI；之前的页面布局、卡片命名、Command 分组和视觉组件均可删除。
- 活动 UI 必须完整显示控制器业务数据；仅凭据和原始响应体继续排除在复制/导出报告之外。
- 策略组必须保持控制器返回顺序，任何刷新、搜索、选择、展开或导航都不能改变原始顺序。
- 当前策略组与节点名称使用中间截断，违反全量可见要求；新界面必须通过换行、可扩展列宽和详情区完整展示名称。
- `scripts/verify-real-controller-source.mjs` 仍硬编码已归档的上一任务路径和 `in_progress` 状态，当前已经无法独立运行；本任务必须将校验契约迁移到长期 spec/docs 与新架构。
- `AGENTS.md`、`docs/UI_GUIDELINES.md` 和 `.trellis/spec/frontend/workbench-ui-contract.md` 仍包含上一轮“数据区不得使用玻璃”等旧视觉限制，需要在本任务完成时同步为新的长期规则。

## Requirements

### Design Direction

- Design read：面向高频代理控制工作的原生 macOS 专业工作台，使用克制、清晰、具有物理反馈的 Liquid Glass 控制层，内容层保持高可读性和数据密度。
- 使用 `design-taste-frontend` 进行反模板化审计，同时以 macOS HIG、SwiftUI 和 Apple Liquid Glass 规范为最终准则。
- 采用系统 `NavigationSplitView`、统一工具栏、标准菜单、SF Symbols、原生搜索和键盘导航；删除会遮盖系统材质的自定义窗口/导航背景。
- Liquid Glass 主要用于侧栏选择态、工具栏、命令控件、策略组选择块、可交互筛选器和紧凑检查器；表格、日志和长文本内容不得层层叠加玻璃。
- 允许使用 Rose Pine 色彩作为克制的语义 tint 和状态色，但背景材质改由系统外观、窗口内容和 Liquid Glass 决定，不再铺满固定米色/深紫底色。
- 统一形状规则：窗口与系统控件遵循 macOS 27 同心圆角；自定义玻璃块只使用少量明确半径，不混用大量尺寸。
- 动效用于玻璃选择、展开、检查器切换和状态变化；支持 Reduce Motion、Reduce Transparency，不能影响高频操作效率。

### Information Architecture

- 重新组织侧栏信息架构，去掉含义模糊的“Command 菜单”分区；导航名称直接对应真实数据区域。
- 用户已确认将侧栏收敛为 5 个主区：概览、代理、活动、规则与来源、系统。原有功能在对应主区内通过原生分段导航或同窗口子导航切换。
- 保留并重新设计概览、策略组、连接、规则、来源、日志、核心配置、核心操作、Tailscale、诊断和设置的数据能力，可合并导航层级但不得丢失功能。
- 工具栏只保留当前页面高频动作、搜索和控制器级状态；低频动作进入标准菜单或同窗口检查器。
- Command 菜单改成符合 macOS 的 `View` 导航命令和 `Controller` 操作菜单，命令名称、快捷键、可用状态与当前页面一致。
- 普通浏览、筛选、节点选择、策略切换、延迟测试和加载更多都在主窗口完成，不使用普通 sheet、popover 或 modal。仅当控制器真实提供固定选择状态和取消动作时，才在同窗详情中显示取消入口。

### Policy Groups

- 策略组重做为固定顺序的 Liquid Glass 选择块；每块清晰显示组名、类型、当前策略/节点、成员数、运行状态和延迟测试入口。
- 宽窗口使用稳定的选择区加同窗口详情区；窄窗口使用原位展开。两种布局都不能更改数组顺序或造成选择后视觉重排误解。
- 点击策略组后，在同一窗口查看和选择策略/节点；节点列表使用可扫描的真实内容行，选中态、延迟、类型、不可用和操作中状态清晰可见。
- 使用原生玻璃交互与必要的 `GlassEffectContainer`/玻璃身份过渡，但不把每个节点行做成独立玻璃卡片。
- 策略组和节点名称不得使用中间截断；长名称在选择块或详情区换行，并支持文本选择。

### Overview And Data Surfaces

- 概览重新建立视觉主次：控制器身份与健康、实时上下行、累计流量、连接/策略组/规则/来源数量、运行时状态和端点状态。
- 仅当真实实时采样存在时显示短时流量图；采样历史由真实流事件形成，不生成 mock、补零趋势或虚构指标，并提供文字/表格辅助信息。
- 连接、规则、来源和日志采用原生高密度列表/表格与同窗口详情，不用重复卡片包裹每一行。
- 核心配置、核心操作、诊断和设置按任务分组，危险操作明确但不过度使用警告色或确认弹窗。
- 所有页面必须具备 loading、empty、unavailable、error、partial 和 live/paused 状态，状态内容来自真实模型。

### Preferences And Accessibility

- 中英文切换、跟随系统/浅色/深色、四档字体大小必须立即作用于新外壳和全部数据页面。
- 系统外观应真正控制窗口材质、文本和玻璃表现；不使用固定颜色模拟浅色/深色。
- 所有图标按钮有本地化 tooltip 和辅助功能标签；侧栏、策略组、表格、检查器和工具栏可完整键盘操作。
- 在 Reduce Transparency 下提供清晰的系统实色/材质表现；正常文字对最复杂背景仍满足可读性要求。

### Engineering Boundaries

- 真实控制器适配器、数据获取、命令执行、凭据存储和导出安全边界保持不变，除非新 UI 所需的真实展示状态必须补充纯展示模型。
- 可以删除或重命名所有旧 UI 专用抽象、样式、布局和本地化键；不得为了兼容旧视觉概念添加包装器。
- 源码校验器不得依赖某个活动/归档 Trellis 任务目录或任务状态；稳定约束写入 `.trellis/spec/` 与 `docs/` 后由校验器检查代码行为。
- 不新增 mock data，不下载/启动/捆绑真实核心，不修改系统代理、环境、网络或防火墙。
- 所有开发临时文件写入仓库 `tmp/codex/`，任务结束清理不再需要的产物。

## Acceptance Criteria

- [x] 应用首屏、侧栏、工具栏和内容层形成清晰的 macOS 27 Liquid Glass 层级，且不再表现为固定底色上的重复描边卡片。
- [x] 旧 `MicaSurface`/`MicaPanel`/自定义玻璃按钮体系被删除或收敛为少量有明确语义的新组件，不保留旧 UI 兼容包装。
- [x] 侧栏和菜单使用直接、可理解的导航/命令分组；没有“Command 菜单”一类抽象标题或重复入口。
- [x] 策略组以固定顺序的玻璃选择块呈现，点击后在同一窗口完成成员浏览、延迟测试和策略/节点选择；刷新、搜索、选择及导航后顺序不变。
- [x] 控制器、策略组、节点、连接 ID、请求地址、规则 payload、来源名和日志正文不使用中间截断或遮罩；长内容可完整查看和选择。
- [x] 概览只显示可追溯的真实指标；实时图表仅由真实流量样本生成，没有 mock、插值伪造或无数据图表。
- [x] 连接、规则、来源、日志、配置、操作和诊断页面采用适合内容的原生高密度布局，并保留全部真实业务字段。
- [x] 中英文、系统/浅色/深色外观和四档字体大小在所有新页面中立即生效。
- [x] Reduce Motion、Reduce Transparency、VoiceOver、完整键盘导航、tooltip 和点击区域通过人工与自动检查。
- [x] 正常、加载、空、部分可用、错误、操作中和不可用状态均有一致且真实的呈现。
- [x] 活动 UI 全量显示控制器业务数据，复制/导出继续排除凭据与原始响应体。
- [x] 源码规则校验、字符串目录解析、Swift 构建、单元测试、运行时 smoke 和至少两种外观/语言/字体组合的 UI smoke 通过。
- [x] 设计预检覆盖所有主页面，并验证正常透明度与 Reduce Transparency 下的对比度、布局、文本截断和玻璃层叠。
- [x] `verify-real-controller-source.mjs` 不再读取已归档任务或断言任务状态，且新的 Liquid Glass/spec 契约可独立验证。

## Out Of Scope

- 不改变控制器协议和远程 API 语义。
- 不提供旧版 UI 切换选项。
- 不兼容 macOS 27 之前的平台。
- 不在本任务中运行或管理本地代理核心。
