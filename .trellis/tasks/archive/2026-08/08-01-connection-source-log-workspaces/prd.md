# 连接、来源与日志工作区重构

## Goal

把连接、来源和日志从外观相近的通用数据表，重构为三个用途明确的原生 macOS
工作区：连接用于追踪真实路由链和处置会话，来源用于管理控制器报告的来源生命
周期，日志用于高速浏览与定位事件。优化信息层级、同窗口交互和视觉一致性，
同时保留既有数据完整性、投影性能、控制器能力门控和滚动行为。

## Confirmed Facts

- 三页目前都使用 `WorkbenchDataBrowserScaffold`、单棵原生 `Table`、按需
  `.inspector` 和离散宽度模式。该结构性能边界正确，但页面的任务差异主要只
  体现在列和命令上，视觉与操作语言过于同质。
- 连接页已有活动/已关闭范围、搜索、用户排序、滚动恢复、按稳定 ID 更新的实时
  指标、滚动期间排序冻结、单连接/分组/全部关闭及完整详情。
- 来源页已有来源类型过滤、搜索、用户排序、更新全部进度、单来源更新、健康
  检查、重载及完整控制器字段。
- 日志页已有来源顺序、级别过滤、搜索、增量 append/drop 投影、Follow Newest、
  Jump to Newest、滚动恢复及完整事件详情。
- `07-30-vertical-scroll-jank` 已建立单 Table、固定行几何、增量投影和单纵向
  滚动所有者边界。本任务不能为了视觉变化恢复多棵 Table、卡片墙或昂贵行布局。
- `07-30-localization-placeholder-settings-alignment` 已覆盖设置、配置、操作、
  诊断和控制器管理布局；`07-31-rules-policy-workspace-innovation` 已覆盖规则
  与策略组。首页已有个性化模块、图表和完整拓扑架构。

## Requirements

### R1. Three Purpose-Specific Workspaces

- 三页共享排版、语义色、命令和详情原语，但不得复制同一个“标题 + 筛选 +
  通用列 + 操作列”布局。
- 连接页以真实连接路径和处置为核心；来源页以更新、健康和内容状态为核心；
  日志页以时间、级别、消息和跟随状态为核心。
- 保留单棵原生 `Table` 作为高密度数据平面；创新集中在扫描层级、焦点区域、
  同窗口详情和任务相关交互，不改成卡片墙。

### R2. Connections Workspace

- 保留活动/已关闭、搜索、用户排序、来源顺序、稳定选择、滚动恢复、实时指标
  增量、排序冻结和全部现有关闭操作。
- 扫描行首先表达连接身份、目标和真实路由结果；进程、网络、流量和时间作为
  次级信息。
- 选中连接时展示完整真实链路和关键统计；未选中时不保留空焦点区域或空详情。
- 完整链路中的策略组名称与当前可见组精确匹配时可跨页打开并激活该组；规则
  类型与 payload 只有唯一精确匹配时才可跨页选择对应规则。
- 重复、缺失或无法确认的规则/策略目标只显示完整值，不进行模糊匹配、首项
  猜测或客户端推断。
- 所有关闭操作继续使用现有 capability、controller ID 和 generation 边界；
  普通选择、检查和导航不触发关闭确认。
- 删除独立操作列。活动连接选中后，单连接关闭和可用的同组关闭进入焦点区；
  关闭全部继续位于命令栏。已关闭连接不显示关闭命令。

### R3. Sources Workspace

- 保留来源类型过滤、搜索、用户排序、来源上报数据和现有更新/健康检查/重载
  操作。
- 扫描行首先表达来源名称、种类和内容规模，再表达更新时间、健康及可操作性。
- 删除表格中的独立操作列。选中来源后，在表格上方显示紧凑焦点区，表达
  `来源 → 内容规模 → 最近更新/健康状态`，并在右侧提供单项更新和健康检查。
- Update All 与重新加载继续位于页面命令栏；Update All 的实时进度继续在
  同一页面呈现。检查器只承载完整字段、错误和最近结果，不重复主要命令。
- 不合成测试 URL、订阅信息、更新时间、健康结果或成功状态；缺失值明确保持
  未报告。

### R4. Logs Workspace

- 保留日志来源顺序、增量投影、级别过滤、搜索、Follow Newest、Jump to
  Newest、稳定选择、滚动锚点和完整详情。
- 时间与级别形成稳定定位栏，消息/载荷是主要扫描内容；结构化字段只在需要时
  展开，不把每行做成多层卡片。
- 每行使用约 3 点宽的低饱和度语义色轨辅助快速定位级别，同时始终保留明确
  级别文字。错误使用红色、警告使用琥珀色、debug/trace 使用紫色，普通信息
  使用青色或次要色；不得只依赖颜色表达语义。
- Follow Newest 的开启、暂停和回到底部状态必须清晰但克制；用户选择或手动
  滚动继续停止自动跟随。
- 不排序日志、不伪造时间、不折叠或脱敏控制器报告的可见日志内容。

### R5. Shared Native And Performance Boundaries

- 使用 SwiftUI、原生 `Table`、系统 inspector、SF Symbols 和现有 Workbench
  原语。本任务不引入第三方依赖或 AppKit 表格桥接。
- 每页只有一个纵向滚动所有者和一棵 Table；行保持固定、单行、可选择的扫描
  几何，完整换行内容留在同窗口详情。
- 静态结构、筛选/排序和高频指标保持独立失效路径；不可见页面不执行昂贵投影。
- 所有业务数据全量可见；诊断导出继续排除凭据和原始响应体。
- 新文案同时提供英文与简体中文，并补齐 help、键盘和辅助功能语义。

### R6. Scope

- 首页和管理页只接受因共享原语产生的必要一致性修复，不重新设计信息架构。
- 不修改控制器 API、DTO、领域模型、认证、连接协议、日志语义或来源操作语义。
- 不添加 mock 数据，不连接真实控制器、9090 或核心，不修改系统网络。
- 实现完成后集中验证，不在每个小改动后运行完整构建。

## Acceptance Criteria

- [ ] AC1: 连接、来源和日志具有可区分且符合各自任务的扫描层级，同时保持统一
  的 Workbench 视觉语言。
- [ ] AC2: 三页各自只构造一棵原生 `Table`，没有卡片墙、嵌套内容玻璃、重复
  表格树或新增纵向滚动冲突。
- [ ] AC3: 连接页完整保留真实链路、活动/已关闭范围、实时指标、排序、搜索、
  关闭能力与完整详情；唯一精确匹配的规则和策略组可跨页导航，模糊或重复目标
  不产生伪链接；表格没有独立操作列。
- [ ] AC4: 来源页完整保留来源字段、过滤、排序、Update All、单项更新、健康
  检查、重载和完整详情；表格无独立操作列，单项操作只在选中来源的焦点区
  出现。
- [ ] AC5: 日志页完整保留来源顺序、增量更新、级别过滤、搜索、Follow Newest、
  Jump to Newest、滚动恢复和完整详情；级别使用窄色轨与文字双重编码。
- [ ] AC6: 未选择数据时没有空焦点条或常驻空 inspector；选择和关闭详情不改变
  控制器业务状态。
- [ ] AC7: 常规、紧凑、最窄宽度及超大字体下，主要字段和操作可达且无重叠或
  横向页面滚动。
- [ ] AC8: 投影、排序、滚动、generation、操作能力和本地化防回归测试通过。
- [ ] AC9: 完整 Swift 构建/测试、源码契约、本地化 JSON、HIG 和差异检查通过。
- [ ] AC10: 未访问真实控制器、9090、核心或系统网络，未运行旧 runtime smoke。

## Out Of Scope

- 首页图表、拓扑和个性化架构重构。
- 设置、配置、操作、诊断和控制器管理布局重构。
- 规则或策略组工作区再次重构。
- 新控制器能力、客户端推断链路、第三方运行时代码和真实控制器联调。
